---
title: "Exercise 2: Loops and Lists"
---

Write a program that reads a list of exam marks from `marks.txt`, one
mark per line, and prints:

- the mean mark,
- the highest and lowest mark,
- how many marks are a first (70 or above).

## Things to check

- an empty file should print a sensible message, not crash
- marks outside 0-100 should be rejected with an error, not silently
  averaged in
- the file may have trailing blank lines

Submit a single `.py` file.
